Norme sulla privacy

Registro Video · aggiornate il 17 novembre 2026

Registro Video è uno strumento personale di Reverse Production per gestire i propri canali YouTube (cos'è). Usa i servizi API di YouTube.

Quali dati usa

Con il permesso del proprietario del canale, legge tramite l'API di YouTube i dati dei suoi canali: elenco dei video, titoli, descrizioni, stato di pubblicazione, data di uscita, nome del file caricato e numero di visualizzazioni. Su richiesta del proprietario modifica titolo, descrizione, tag, miniatura e data di uscita dei suoi video.

Non raccoglie dati di altre persone, come spettatori o commenti.

Dove restano

I dati e le chiavi di accesso restano sul computer del proprietario. Un riepilogo (titolo, stato, data e visualizzazioni dei video) è visibile solo nel suo registro privato. I dati non vengono venduti, ceduti o condivisi con nessuno e non servono per pubblicità.

Come togliere l'accesso

L'accesso si può revocare in ogni momento dalla pagina delle autorizzazioni dell'account Google: myaccount.google.com/connections. Dopo la revoca lo strumento non può più leggere né modificare nulla; i dati salvati sul computer si cancellano eliminando la cartella delle credenziali.

Servizi di Google e YouTube

Usando Registro Video si accettano i Termini di servizio di YouTube. Per il trattamento dei dati da parte di Google valgono le Norme sulla privacy di Google.

Privacy policy (English)

Registro Video is a personal tool used by Reverse Production to manage its own YouTube channels, and it uses YouTube API Services. With the channel owner's permission it reads data about the owner's channels through the YouTube API (video list, titles, descriptions, publishing status, release date, uploaded file name, view counts) and, when the owner asks, updates the title, description, tags, thumbnail and release date of the owner's videos. It does not collect data about other people.

Data and access keys stay on the owner's computer; a summary is shown only in the owner's private log. Data is never sold, transferred or shared, and is not used for advertising. Access can be revoked at any time at myaccount.google.com/connections.

By using Registro Video you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Contact: through the YouTube channels listed above.
